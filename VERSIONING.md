# Versioning

The authoritative version is `metadata.version` in `code-animation/SKILL.md`. Repository tags use `v` plus that value; release ZIP filenames use `code-animation-<version>.zip`. The guide/application versions mentioned in references are separate historical examples.

Current version: 0.1.0-alpha.6. The skill remains an alpha while portability and broader workflow acceptance continue. One accepted guide and structural checks do not establish universal compatibility.

Published archives and tags are preserved. Meaningful future updates increment the version and update the change record before publication.
