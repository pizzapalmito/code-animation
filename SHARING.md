# Code Animation skill

Version: 0.1.0-alpha.6

Extract the code-animation folder into your Codex skills directory (usually ~/.codex/skills/). If that skill already exists, back it up and compare versions before replacing it. Open a new chat so Codex can discover the installed skill.

Example request:
> Use $code-animation to create a task-based guide for my app using the approved SBM walkthrough preset, with narration and an offline video library.

This archive contains the skill instructions, production references, approved visual/narration preset, and planning worksheet. It does not contain the SBM application, videos, private data, voice models, rendering software, or companion skills.

The skill defaults to HyperFrames and refers to the hyperframes and hyperframes-cli skills, relevant GSAP guidance, and a selected creative skill. Install the companion skills needed for your workflow; the SKILL.md routes explain which ones apply. Barty-Bart creative skills: https://github.com/Barty-Bart/motion-graphics . Huashu art-library routes and HTML/Electron capture helpers are referenced separately and are not bundled here.

Production needs a compatible Node.js/npm environment, HyperFrames, a browser, FFmpeg/FFprobe, and any selected narration dependencies. Follow references/hyperframes-preflight.md on the recipient machine. This ZIP does not install software automatically or certify those dependencies are available.

The approved preset is documented in full. The optional path to the author's historical source project was generalized for sharing; that project is not required to read or use this skill. All other skill files retain their installed contents. Verify the new app's workflows and use the recipient's own authorized demo data and branding.
